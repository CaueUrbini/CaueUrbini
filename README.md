### 📁 [InclusiveCityHub](https://github.com/CaueUrbini/inclusiveCityHubBackend) · *Team project, Back-end*

**What I did:** built the Node.js API where users register, log in and follow daily events. Moderators and companies create and validate event postings.
**Stack:** `Node.js` `PostgreSQL` `Docker Compose` `GitHub Actions`
